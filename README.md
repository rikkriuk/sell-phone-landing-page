# 📱 React Tailwind Landing Page – Jual HP Bekas

Landing page modern untuk layanan **jual beli HP bekas / rusak**, dibangun dengan **React**, **Tailwind CSS**, dan **Motion (Framer Motion terbaru)**.  
Didesain cepat, responsif, dan fokus ke konversi via **WhatsApp**.

---

## ✨ Fitur Utama

- ⚡ React + Vite (fast dev & build)
- 🎨 Tailwind CSS (utility-first styling)
- 🎬 Motion (`motion/react`) untuk animasi halus
- 📱 Responsive (mobile-first)
- 💬 CTA WhatsApp dengan pesan otomatis
- ⭐ Section testimonial pelanggan
- 🔗 Navigasi WhatsApp buka di tab baru

---

## 🧰 Tech Stack

- **React 18**
- **Vite**
- **Tailwind CSS**
- **Motion (motion/react)**
